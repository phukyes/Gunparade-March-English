Gunparade March - English Translation
Playtest build GPM-EN58
Translated by Phukyes/Asterhex
Discord: https://discord.gg/xcyEFG4YG8

this is a playtest build. There is a TON of text in this game and i am just one person.
you wont encounter all text in one playthrough of the game. if you see any Japanese characters
that is a bug not a missed translation. 100% of the text has been translated. if you encounter any
bugs please reach out to me via discord with a screenshot and the current build of the patch.

---------------------------------------------------------------------------
you will need
---------------------------------------------------------------------------
Your own disc image of the original Japanese game:
  Koukidou Gensou Gunparade March (Japan)   (single-track BIN/CUE)

It must match this dump exactly:
  File size : 440,372,016 bytes
  CRC32     : B867C065
  MD5       : 66709F78ABFDC5A4CC40A8A47C274441
  SHA-1     : 1FD53D0FCDC2D9C8FA61E5640206B78A5E0ED0ED

This patch does not contain the game.

You can patch the .BIN file for the game with xdelta or deltapatcher. its pretty
straightforward. tutorials exist online.

---------------------------------------------------------------------------
NOTES
---------------------------------------------------------------------------
- Save states made with an older playtest build may show old text in some menus.
  Memory card saves carry over between builds without problems.
- A few pieces of artwork with text baked into pictures are still in Japanese. 
  Those are a work in progress as there is quite a bit.
- If you would like to assist in the effort you can reach me via discord.
